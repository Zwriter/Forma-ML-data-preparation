**Input**: [spec.md](spec.md), [plan.md](plan.md), [research.md](research.md),
[data-model.md](data-model.md), [contracts/ipc.md](contracts/ipc.md),
[contracts/ui.md](contracts/ui.md), [quickstart.md](quickstart.md)

**Tests**: Required (constitution III). Every task that changes behaviour writes the failing test
first, makes it pass with the smallest change, then refactors. Engine tests use
`app/engine/.venv/Scripts/python.exe -m pytest <path>`. Desktop tests use
`npx vitest run <path>` in `app/desktop`. Layout, scrolling, and focus checks go in Playwright
(`npm run test:ui`).

**Paths**: Engine paths are relative to `app/engine/`, desktop paths to `app/desktop/`.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: User story from spec.md (US1–US6)
